# Student Exam Result Classifier

## About
This is a Machine Learning classification project to predict whether a student will pass or fail an exam based on their study hours and attendance.

## Dataset
A small dataset containing 10 students with the following features:
- study_hours: Number of hours studied
- attendance: Number of absences
- passed: Target variable (1 = Passed, 0 = Failed)

## Model
Logistic Regression (Classification)

## Result
Model Accuracy: 1.0 (100%)
*(Note: The high accuracy is due to the very small and simple dataset. In real-world scenarios, data is much larger and more complex.)*

## Libraries
- pandas
- scikit-learn
